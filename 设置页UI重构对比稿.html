字色 before → after

说明里的强调高亮

现状#7cb9e8 蓝
→
建议#16915e 翠绿

硬编码蓝与全局翠绿强调撞色系。改用 --accent 后强调统一。

输入框 / 下拉选中值

现状--text-dim
→
建议--text-2

亮色选中值发灰、且与暗色(已用 text-2)不一致。提深一档更醒目、两套统一。

说明文字 hint

现状 ~2.8:1#97948c · 11.5px
→
建议 ~4.5:1#6f6c64 · 12px

小字 + 浅灰对比度低于 WCAG AA。加深一档达标。

警告色

现状#e8a17c 散落 2 处
→
建议--warn 变量

硬编码橙入 CSS 变量,集中管理、随主题切换。

可点链接（详情 / 展开）

现状accent · 同标题色
→
建议text-2 + 虚线

默认中性 + 虚线下划线表「可点」,hover / focus 才点亮 accent。不再与标题撞色,可点 / 不可点一眼分清。
